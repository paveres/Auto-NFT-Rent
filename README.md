# Auto NFT Rent — аренда NFT-подарков Telegram на FunPay

Плагин для автоматической **аренды NFT-подарков Telegram** по заказам **FunPay**. Покупатель оплачивает лот, получает картинку со свободными подарками, выбирает номер, подтверждает вход в Telegram, и подарок появляется в его профиле. В конце срока подарок возвращается сам. Работает на Windows и Linux.

## Возможности

- автовыдача NFT-подарков Telegram после оплаты на FunPay
- картинка со свободными моделями, выбор по номеру
- быстрая привязка через вход в Telegram или ручная через fragment.com
- автоматический возврат подарка по окончании аренды
- продление повторной оплатой того же лота
- управление через Telegram-бота
- автосоздание лотов, команды `!подарки`, `!модели`, `!срок`, `!продлить`

## Запуск

1. Скачайте проект и распакуйте
2. Запустите `start.bat` (Windows) или `sh start.sh` (Linux)
3. Ответьте на вопросы программы

Нужны Python 3.10+, golden_key FunPay и ключ API из [@BlimyStarsBot](https://t.me/BlimyStarsBot).

[Подробная инструкция](https://telegra.ph/Auto-NFT-Rent-ustanovka-i-nastrojka-11-19) · [Документация API](https://docs.rusksmm.ru)

## Лот

В названии: подарок и срок. В описании отдельной строкой: `!rent`

Продление: покупатель оплачивает тот же лот ещё раз.
