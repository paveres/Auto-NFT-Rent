# Auto NFT Rent

FunPay bot for renting Telegram NFT gifts automatically. Auto-delivery, auto-return and extension. Python, Windows / Linux.

Quick start: run `start.bat` (Windows) or `sh start.sh` (Linux) and answer the questions. You need Python 3.10+, a FunPay golden_key and an API key from [@BlimyStarsBot](https://t.me/BlimyStarsBot).
